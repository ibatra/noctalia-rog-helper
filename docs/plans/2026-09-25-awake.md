# Sleep & lid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a caffeinate-style "Sleep & lid" feature to rog-helper. It covers sessions with timers, lid rules per power source, clamshell screen handling, a power-button action, and safety stops, and all of it is driven by logind inhibitor locks held by a user unit.

**Architecture:**
- **Backend.** A new bash backend, `rog-helper/bin/awakectl`, owns the config and runs the watcher (`awakectl watch`, as the unit `rog-helper-awake.service`). The watcher holds `systemd-inhibit` children and drives Hyprland DPMS or monitor rules.
- **Decision logic.** One pure bash function, `decide`, turns config plus machine inputs into wanted locks and actions, and is table-tested.
- **Panel.** A new Luau module, `rog-helper/awake_view.luau`, renders the sub-view from building blocks that `panel.luau` passes in.
- **Other surfaces.** The bar widget and a new Control Center shortcut read `awakectl status`.

**Tech Stack:**
- bash (`set -u`), coreutils, `systemd-inhibit` (systemd 261), `udevadm`, `jq`, `hyprctl` (Hyprland 0.56.2, Lua config)
- Noctalia 5.1 Luau plugin API 30

**Spec:** `docs/specs/2026-09-25-awake-design.md`. Read it first; this plan implements it.

## Global Constraints

- Repo: `~/.local/share/noctalia-plugins`, branch `awake`. Plugin dir: `rog-helper/`.
- **No live mutation of the user's Hyprland while developing.** Never run `hyprctl dispatch`, `eval` or `reload` against the live session. Hyprland calls are tested through the `AWAKE_HYPRCTL` stub, or in the nested harness `~/.cache/hands-port/nested`.
- **Never take real inhibitor locks** except in Task 6's verification step. Never suspend the machine. Never run sudo or pkexec.
- **Mirror rogctl's conventions:**
  - `set -u`
  - `run()` dry-run wrapper printing `dry-run: <cmd>` to fd 9
  - `--dry-run` as the first argument, `ROG_DRY_RUN=1`, or the file `~/.config/rog-helper/dry-run`
  - exit codes 0 ok, 2 bad usage, 3 blocked (message on stdout), 1 failed
  - `key=value` output
  - `# ── name ───` section dividers
  - a usage header that doubles as help
- **Lock modes:** idle is `--mode=block`, and sleep and handle-lid-switch are `--mode=block-weak`. Always pass `--no-ask-password --who="ROG helper"`.
- The eDP name is discovered as the first `hyprctl monitors -j` entry whose name starts with `eDP`. It is never hard-coded.
- **Copy tone:** sentence case, no trailing period on labels or notes, and say the consequence plainly (for example "Sleeps when the lid closes").
- `ac_online` is copied verbatim from rogctl.
- **Commits:** scope prefix (`awakectl:`, `Panel:`, `Widget:`, `README:`), lowercase summary, `- ` bullet body, and the trailer `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

1. **Unplugging with the lid closed on battery, rule Sleep.** The lid lock must be released, and the laptop must suspend: logind first, then the `systemctl suspend` fallback after 10 s. It must never stay awake in a bag.
2. **Timer expiry while the watcher was not running** (reboot, logout). The session must read as ended when the watcher starts, and no lock may be taken.
3. **The watcher killed with SIGKILL, or restarted.** No stray `ROG helper` locks may survive the next start.
4. **Lid closed with the eDP DPMS-off, then Noctalia's idle resume turns every monitor on.** The panel must go dark again within about 2 s.
5. **A power-key press that woke the machine** (within 5 s of resume) must do nothing.

Each has a test in its owning task: 1 and 4 in Task 2, 2 in Task 1, 3 in Task 2, and 5 in Task 3.

# Minimal assertions for the awakectl tests. Source, then call; `finish` exits
# non-zero if anything failed.
FAILS=0; PASSES=0
eq() {  # eq <name> <expected> <actual>
  if [ "$2" = "$3" ]; then PASSES=$((PASSES + 1))
  else FAILS=$((FAILS + 1)); printf 'FAIL %s\n  want: %s\n  got:  %s\n' "$1" "$2" "$3"; fi
}
has() {  # has <name> <needle> <haystack>
  case "$3" in *"$2"*) PASSES=$((PASSES + 1)) ;; *) FAILS=$((FAILS + 1)); printf 'FAIL %s\n  missing: %s\n  in: %s\n' "$1" "$2" "$3" ;; esac
}
lacks() {
  case "$3" in *"$2"*) FAILS=$((FAILS + 1)); printf 'FAIL %s\n  unexpected: %s\n' "$1" "$2" ;; *) PASSES=$((PASSES + 1)) ;; esac
}
finish() { printf '%d passed, %d failed\n' "$PASSES" "$FAILS"; [ "$FAILS" = 0 ]; }
HERE=$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)
AWAKECTL=$HERE/../bin/awakectl

   Also include the dry-run and exit-code lines. The tagline is: `awakectl - Sleep & lid backend for the ROG helper Noctalia plugin.`
2. **Globals.**
   - `set -u`, and the dry-run detection exactly as in rogctl (lines 34-37).
   - `SELF=$(readlink -f "$0")`, `exec 9>&2`, `log`, `run`, `rd`.
   - `CONF_DIR=${AWAKE_CONF_DIR:-${XDG_CONFIG_HOME:-$HOME/.config}/rog-helper}`, `CONF=$CONF_DIR/awake`, `STATUS=$CONF_DIR/awake.status`.
   - `SYS=${AWAKE_SYSROOT:-}`, `HYPRCTL=${AWAKE_HYPRCTL:-hyprctl}`, `UNIT_DIR=${XDG_CONFIG_HOME:-$HOME/.config}/systemd/user`, `UNIT=rog-helper-awake.service`.
   - `now() { printf '%s' "${AWAKE_NOW:-$(date +%s)}"; }`
3. **Defaults** (a single source of truth):
```bash
DEFAULTS="session=none kind=system mins=60 until= lid_ac=awake lid_bat=sleep lid_screen=off lid_monitor=dpms power_key=none stop_battery=20 stop_unplug=0 stop_hot=1 hot_c=95 boot_id="

cfg_get() { local v; if [ -f "$CONF" ] && v=$(grep -m1 "^$1=" "$CONF"); then printf '%s' "${v#*=}"; else default_of "$1"; fi; }
```
   `cfg_set` is copied from rogctl's (flock on `$CONF_DIR/.awake.lock`, mktemp, mv, no-op when unchanged, dry-run prints `dry-run: set k=v in $CONF`). `load_config` loops over `DEFAULTS` and does `printf -v "C_${k}" '%s' "$(cfg_get "$k")"`.
4. **Validation.** `valid KEY VALUE` returns 0 or 1, one allowed set per key:
   - session `none|system|screen`, kind `system|screen`
   - mins `^[0-9]+$` (0–1440; 0 means until stopped), until `^[0-9]*$|^inf$`
   - lid_ac `awake|sleep`, lid_bat `sleep|session|awake`
   - lid_screen `off|lock`, lid_monitor `dpms|disable`
   - power_key `none|lock|sleep|menu`
   - stop_battery 0–50, stop_unplug and stop_hot `0|1`, hot_c 70–105
5. **`decide`.** Pure: no I/O, no subshells, no `date`. Contract:
   - **Inputs:** every `C_*` above, plus `I_ac` (0/1), `I_prev_ac` (0/1), `I_lid` (open/closed), `I_bat` (integer or empty), `I_hot` (0/1, already sustained for 60 s), `I_now` (epoch), `I_ext` (0/1, an external output is connected).
   - **Outputs:**
     - `W_idle`, `W_sleep`, `W_lid` (0/1)
     - `W_screen` (`on|dpms|disable`)
     - `W_lock` (0/1: lock the session while the lid is closed and the screen is off)
     - `W_suspend` (0/1: the lid is closed, nothing keeps the machine up, and it should be asleep)
     - `W_end` (empty, or `time|battery|unplug|hot`: the session must end now)
     - `W_why` (caption text)
```bash
decide() {
  local session=$C_session low=0 hotlid=0 rule
  W_end=
  [ -n "$I_bat" ] && [ "${C_stop_battery:-0}" -gt 0 ] && [ "$I_ac" = 0 ] && [ "$I_bat" -lt "$C_stop_battery" ] && low=1
  [ "$C_stop_hot" = 1 ] && [ "$I_hot" = 1 ] && [ "$I_lid" = closed ] && [ "$I_ac" = 0 ] && hotlid=1
  if [ "$session" != none ]; then
    if [ -n "$C_until" ] && [ "$C_until" != inf ] && [ "$I_now" -ge "$C_until" ]; then W_end=time
    elif [ "$low" = 1 ]; then W_end=battery
    elif [ "$C_stop_unplug" = 1 ] && [ "$I_prev_ac" = 1 ] && [ "$I_ac" = 0 ]; then W_end=unplug
    elif [ "$hotlid" = 1 ]; then W_end=hot
    fi
    [ -n "$W_end" ] && session=none
  fi
  W_idle=0 W_sleep=0 W_lid=0 W_lock=0 W_suspend=0 W_screen=on W_why=
  [ "$session" = screen ] && W_idle=1
  [ "$session" != none ] && W_sleep=1
  if [ "$I_ac" = 1 ]; then rule=$C_lid_ac; else rule=$C_lid_bat; fi
  if [ "$rule" = awake ] || { [ "$rule" = session ] && [ "$session" != none ]; }; then W_lid=1; fi
  # on battery the floor and the heat stop also keep the lid from holding the machine up
  if [ "$I_ac" = 0 ] && { [ "$low" = 1 ] || [ "$hotlid" = 1 ]; }; then W_lid=0; fi
  if [ "$I_lid" = closed ]; then
    if [ "$W_lid" = 1 ] || [ "$I_ext" = 1 ]; then
      W_screen=dpms
      [ "$I_ext" = 1 ] && [ "$C_lid_monitor" = disable ] && W_screen=disable
      [ "$C_lid_screen" = lock ] && W_lock=1
    else
      W_suspend=1
    fi
  fi
  local parts=()
  [ "$session" = screen ] && parts+=("Awake session, screen on")
  [ "$session" = system ] && parts+=("Awake session")
  if [ "$W_lid" = 1 ] && [ "$I_lid" = closed ]; then
    if [ "$I_ac" = 1 ]; then parts+=("lid closed on charger"); else parts+=("lid closed on battery"); fi
  fi
  [ "$I_ext" = 1 ] && [ "$I_lid" = closed ] && [ "$W_lid" = 0 ] && parts+=("lid closed with a monitor")
  local IFS=,; W_why=${parts[*]}; W_why=${W_why//,/ · }
}
```
   Note on "why names lid on charger": with the lid closed on the charger, W_lid=1 and I_lid=closed, so the caption reads "lid closed on charger", which the test expects. The test also expects the caption to be empty when nothing is held on battery.
6. **Sensors**, all prefixed by `$SYS` and all tolerant of missing files:
   - `ac_online` is copied from rogctl, with `/sys/class/power_supply` replaced by `$SYS/sys/class/power_supply`.
   - `lid_state` greps `closed` in `$SYS/proc/acpi/button/lid/*/state`, prints `closed` or `open`, and prints `open` if there is no lid.
   - `battery_pct` reads `capacity` of the first `BAT*`, sorted, and prints empty if there is none.
   - `pkg_temp_c` reads the thermal zone whose `type` is `x86_pkg_temp`, falls back to `TCPU`, divides by 1000, and prints empty if unknown.
   - `edp_name` runs `$HYPRCTL monitors all -j | jq -r 'first(.[] | select(.name|startswith("eDP")) | .name) // empty'`. It uses `all` so that a disabled eDP is still found.
   - `external_connected` prints 1 if any `$SYS/sys/class/drm/card*-*/status` reads `connected` for a connector not matching `eDP`, else 0. It uses DRM rather than Hyprland, so a disabled eDP doesn't matter.
7. **`cmd_status`** prints:
   - every config key as `key=value`
   - `ac=`, `lid=`, `battery=`, `temp=`, `ext=`
   - `left=`: seconds until `until`, `inf`, or empty when there is no session
   - the watcher's status file lines, prefixed: `held=`, `why=`, `screen=`, `ended=` (`reason@epoch` of the last end), `updated=`, all empty if the file is missing
   - `watcher=` (`active|inactive`, from `systemctl --user is-active $UNIT`, or `inactive` if systemctl fails)
   - `has_power_key_bind=` (1 if `grep -rqs 'awakectl power-key' ~/.config/hypr` succeeds)

   A session whose deadline has passed prints as `session=none`: run `load_config`, fill the `I_*` from the sensors, call `decide`, and if `W_end` is set, print `session=none`. This covers Review Focus #2.
8. **Library guard.** Just before dispatch: `[ -n "${AWAKE_LIB:-}" ] && return 0 2>/dev/null`. Then `case "${1:-}" in status) cmd_status ;; *) usage; exit 2 ;; esac`. Later tasks add cases here.

### Task 2: the watcher

**Files:**
- Modify: `rog-helper/bin/awakectl` (new section `# ── watcher ───`, `watch` dispatch)
- Create: `rog-helper/tests/awake_watch.sh`

**Interfaces:**
- Consumes: `load_config`, the sensors, `decide`, `cfg_set`, `run`.
- Produces:
  - `awakectl watch`, which runs until SIGTERM and re-reads config on SIGHUP.
  - The status file `$STATUS` with keys `held` (comma list of `idle,sleep,lid`), `why`, `screen`, `ended`, `updated`.
  - `awakectl watch --once`, for tests: one pass, then exit, with no udev monitor and no sleep, releasing its children on exit.
- Test seams:
  - `AWAKE_INHIBIT` (default `systemd-inhibit`): the command used to take locks.
  - `AWAKE_NOTIFY` (default `noctalia msg notification-show`).
  - `AWAKE_SUSPEND` (default `systemctl suspend`).

**Behaviour:**

1. **Locks.** `lock_take KIND` and `lock_drop KIND` for KIND in `idle|sleep|lid`:
   - Take: `$AWAKE_INHIBIT --no-ask-password --who="ROG helper" --why="$(why_for KIND)" --what=<w> --mode=<m> sleep infinity &`. Record the pid in the assoc array `PID[KIND]`.
     - idle: `--what=idle --mode=block`
     - sleep: `--what=sleep --mode=block-weak`
     - lid: `--what=handle-lid-switch --mode=block-weak`
   - Drop: `kill PID[KIND]; wait` it.
   - In dry run, both print `dry-run: inhibit KIND on` / `dry-run: inhibit KIND off`, and no process starts.
   - `sync_locks` compares the wanted `W_*` with `PID` and takes or drops the difference.
   - **Order:** take new locks before dropping old ones. Always drop `lid` last within a pass.
2. **Stale reap on start.** `reap_stale` parses `systemd-inhibit --list --json=short`, and for each entry with `who=="ROG helper"`, `uid==$(id -u)` and a `pid` that isn't one of ours, sends it `kill`. Use jq: `jq -r '.[] | select(.who=="ROG helper" and .uid==UID) | .pid'`. This is skipped in dry run, and skipped when `AWAKE_INHIBIT` isn't the default (tests).
3. **Exit.** `trap cleanup EXIT INT TERM`. `cleanup` drops every lock, restores the screen if it changed it (DPMS on, or re-enable the eDP rule), and writes the status with `held=`.
4. **Screen**, applied once per pass:
   - `dpms`: if `$HYPRCTL monitors -j` shows the eDP with `dpmsStatus == true`, run `$HYPRCTL dispatch 'hl.dsp.dpms({ action = "off", monitor = "<eDP>" })'`. Checking every pass re-asserts it (Review Focus #4).
   - `disable`: only when `I_ext=1`, and only once 2 s have passed since `I_ext` first became 1 (`EXT_SINCE`). Run `$HYPRCTL eval 'hl.monitor({ output = "<eDP>", disabled = true })'` once, and remember `SCREEN_DISABLED=<eDP>`.
   - `on`:
     - If `SCREEN_DISABLED` is set, run `$HYPRCTL eval 'hl.monitor({ output = "<name>", mode = "preferred", position = "auto", scale = 1.25, disabled = false })'` and clear it.
     - If the watcher turned DPMS off (`SCREEN_DPMS=1`), send the `dpms` `action = "on"` dispatch for that eDP and clear it.
     - Never touch the screen otherwise.
   - Lock: when `W_lock=1` and the lid has just changed to closed (`I_lid=closed`, previous open), run `run noctalia msg session lock`.
   - Every hyprctl call goes through `run` (dry-run safe). **Never call reload.**
5. **Heat.** `HOT_SINCE` is the epoch when `pkg_temp_c >= C_hot_c` first held, and is cleared when the temperature drops below. `I_hot=1` once `now - HOT_SINCE >= 60`.
6. **Ending a session** (`W_end` set):
   - `cfg_set session none`, `cfg_set until ""`, and record `ended=$W_end@$now` in the status file.
   - Notify with `$AWAKE_NOTIFY "ROG helper" "<text>"`:
     - time: "Awake ended: time's up"
     - battery: "Awake ended: battery at N%"
     - unplug: "Awake ended: unplugged"
     - hot: "Sleeping: CPU at N °C with the lid shut on battery"
   - Then call `decide` again with `C_session=none`, so the same pass applies the result.
7. **Suspend fallback.** `SUSPEND_SINCE` is set when `W_suspend=1` first holds, and cleared otherwise. When `now - SUSPEND_SINCE >= 10` and `now - RESUMED_AT >= 30`, run `run $AWAKE_SUSPEND` once and reset `SUSPEND_SINCE`.
   - `RESUMED_AT` is the watcher start time, updated whenever a pass sees the wall clock jump by more than 20 s (a resume).
   - The hot case notifies before the suspend.
   - This covers Review Focus #1: logind normally suspends as soon as the lid lock is dropped, and this is the backstop.
8. **Loop.**
   - Start: `reap_stale`. Record `boot_id` from `/proc/sys/kernel/random/boot_id`. If the config's `boot_id` differs and a session is set, end it silently with reason `boot` and no notification (the spec's restore-state=false). Then `cfg_set boot_id`.
   - `exec 3< <(udevadm monitor --udev --subsystem-match=power_supply 2>/dev/null)`, as in rogctl.
   - Each pass:
     1. `load_config`
     2. read the sensors into `I_*`
     3. `decide`
     4. handle `W_end`
     5. `sync_locks`
     6. apply the screen
     7. the suspend fallback
     8. write the status file atomically (mktemp + mv)
   - Then `read -r -t 2 _ <&3` and drain bursts with `while read -r -t 0.2 _ <&3; do :; done`.
   - `trap 'RELOAD=1' HUP` is just so that `read` returns early; the next pass re-reads config anyway.
   - `I_prev_ac` is the previous pass's `I_ac`, and on the first pass the current one.
   - `--once` does a single pass, then exits through cleanup. For tests: `AWAKE_KEEP=1` skips dropping locks on exit, so the test can see the lock commands as dry-run lines.
